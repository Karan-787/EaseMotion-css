### Ease Badge Component

A responsive, glassmorphism-styled notification badge component designed to highlight unread counts, status indicators, and alerts with smooth fluid animations.

#### Features
* **Glassmorphism Design:** Built with semi-transparent backdrops, subtle borders, and soft blur effects.
* **Animated Pulse:** The `ease-badge-pulse` utility adds a continuous breathing/pulse animation with glowing shadow rings.
* **Flexible Variants:** Includes support for numeric counts, standalone dots (`ease-badge-dot`), and absolute positioning (`ease-badge-floating`).

#### Usage
Include `style.css` and attach the `ease-badge` class alongside any modifier classes to your elements as demonstrated in `demo.html`.
