# Glassmorphism Notification Badge Component (`ease-badge`)

A sleek, responsive, glassmorphism notification badge component built with pure CSS for the EaseMotion gallery. Features an optional smooth pulse and ping animation utility (`ease-badge-pulse`).

## Features
- **Glassmorphism Aesthetic:** Uses `backdrop-filter` blur layers, subtle borders, and soft glowing drop shadows.
- **Micro-Animation Utility:** The `ease-badge-pulse` class introduces a continuous, organic pulsing scale and ring shadow effect.
- **Versatile Variants:** Supports numeric notification counters, text labels, and compact live status dots.
- **Dependency-Free:** Pure, hand-crafted CSS with zero JavaScript requirements.
